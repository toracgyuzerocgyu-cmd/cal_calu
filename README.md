# cal_calu

Google Apps Script で作成した、スプレッドシートの入力データを自動で記録するためのスクリプトです。

## 概要

`Memory.js` は、Google Spreadsheet の `入力` シートから前日のデータを取得し、
`記録用` シートへ転記する処理を行います。

- 取得元シート: `入力`
- 保存先シート: `記録用`
- 前日の日付を自動で計算
- 転記後に入力欄をクリア

## 主な処理内容

- `SpreadsheetApp.getActiveSpreadsheet()` で対象スプレッドシートを取得
- `入力` シートのデータ範囲を取得
- `記録用` シートへ 1 行ずつ値をコピー
- 日付を `yyyyMMdd` 形式で記録
- 転記後に入力内容を初期化

## 使い方

1. Google Spreadsheet を開く
2. シート名を `入力` と `記録用` にする
3. Apps Script に `Memory.js` を追加する
4. スクリプトを実行する

## 想定用途

- 日次データを自動で記録したい
- 手作業による転記を減らしたい
- Google Apps Script の学習用サンプルとして使いたい

## 補足

このリポジトリは、個人学習用のGoogle Apps Script 実装として作成されています。
スプレッドシート連携の基礎を理解するための例として利用できます。
